# 项目学习次序指南

## 📚 学习路径总览

本指南为零基础新手设计，按照由浅入深、循序渐进的原则组织学习内容。

```
入门阶段 (1-2 周)
    ↓
基础阶段 (2-3 周)
    ↓
进阶阶段 (3-4 周)
    ↓
实战阶段 (持续)
```

**阅读材料：**

   - Hook 的基本概念
   - Hook 的类型（PreToolUse, PostToolUse, Stop 等）

   - 实现自定义的安全门规则

**关键概念：**
- 事件驱动

- Q: Hook 和 Plugin 有什么区别？

## 📖 学习方法建议

### 1. 循序渐进

不要跳步！每个阶段都建立在前一阶段的基础上。

```
❌ 错误方式：直接学习高级主题
✅ 正确方式：按顺序逐步推进
```

### 2. 理论 + 实践

**黄金比例：** 30% 理论学习 + 70% 实践操作

```
学习新概念 → 动手实践 → 反思总结 → 再学习
```

### 3. 主动学习

**被动学习（效果差）：**
- 只看不动手
- 死记硬背概念

**主动学习（效果好）：**
- 边学边练
- 提出问题并解决
- 教给别人

### 4. 刻意练习

针对薄弱环节进行专项训练：

```
发现不足 → 专项练习 → 反馈改进 → 循环提升
```

### 5. 建立知识网络

将新知识与已有知识关联：

```
新知识 ←→ 已有知识
       ↓
    知识网络
```

## 💡 学习技巧

### 1. 费曼学习法

**步骤：**
1. 选择一个概念
2. 想象你在教给一个完全不懂的人
3. 遇到卡壳的地方回去重新学习
4. 用简单的语言和类比解释

**效果：** 真正理解而非死记硬背

### 2. 番茄工作法

**方法：**
- 25 分钟专注学习
- 5 分钟休息
- 每 4 个番茄后休息 15-30 分钟

**效果：** 保持注意力集中，避免疲劳

### 3. 思维导图

**用途：**
- 整理知识结构
- 理解概念间的关系
- 复习和记忆

**工具推荐：**
- XMind
- MindNode
- 手绘也可以

### 4. 项目驱动学习

**方法：**
1. 设定一个实际项目
2. 为了实现项目而学习相关知识
3. 遇到问题时针对性解决
4. 完成后复盘总结

**效果：** 学习目标明确，动力充足
