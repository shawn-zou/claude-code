# 项目涉及的多语言知识点详解

## 概述

本项目使用了多种编程语言和技术，每种语言都有其特定的用途和知识点。本文档为零基础新手详细梳理各语言的必学知识点。

## 一、Markdown - 核心配置语言 ⭐⭐⭐⭐⭐

### 1.1 为什么重要？

**用途：**
- Agent 配置文件（所有 Agent 都是 .md 文件）
- 插件文档和说明
- 技能（Skill）描述
- 命令（Command）定义

**特点：**
- 简单易学
- 可读性强
- 支持结构化内容

### 1.2 必学知识点

#### 知识点 1：基础语法

**标题：**
```markdown
# 一级标题
## 二级标题
### 三级标题
#### 四级标题
```

**列表：**
```markdown
- 无序列表项 1
- 无序列表项 2

1. 有序列表项 1
2. 有序列表项 2
```

**代码块：**
````markdown
```javascript
// 行内代码 `console.log()`

// 代码块
function hello() {
    console.log("Hello World");
}
```
````

**链接和图片：**
```markdown
[链接文字](https://example.com)
![图片描述](./image.png)
```

**引用：**
```markdown
> 这是一段引用文字
> 可以有多行
```

#### 知识点 2：YAML Frontmatter

**什么是 Frontmatter？**
文件开头的元数据区域，用 `---` 包裹。

**基本结构：**
```yaml
---
name: agent-name          # 名称
description: 描述文本      # 描述
model: inherit            # 模型选择
color: blue              # 颜色
tools: ["Read", "Grep"]  # 工具列表
---
```

**字段说明：**

| 字段 | 必填 | 说明 | 示例 |
|------|------|------|------|
| name | ✅ | Agent/插件的唯一标识 | `code-reviewer` |
| description | ✅ | 功能描述，包含触发示例 | `用于代码审查...` |
| model | ✅ | 使用的 AI 模型 | `inherit`, `sonnet` |
| color | ✅ | UI 显示颜色 | `blue`, `green` |
| tools | ❌ | 允许使用的工具 | `["Read", "Write"]` |

**完整示例：**
```yaml
---
name: code-reviewer
description: |
  当用户写完代码需要审查时使用此 Agent。
  
  示例：
  <example>
  用户："帮我检查代码"
  助手："我来用 code-reviewer 审查"
  </example>
model: inherit
color: blue
tools: ["Read", "Grep", "Glob"]
---
```

#### 知识点 3：特殊标签用法

**`<example>` 标签：**
```markdown
<example>
Context: 用户刚写完代码
user: "我写完了支付功能"
assistant: "让我审查一下代码质量"
<commentary>
代码写完后的审查触发
</commentary>
assistant: "我使用 code-reviewer Agent 来审查"
</example>
```

**作用：** 定义 Agent 的触发场景示例

#### 知识点 4：结构化内容组织

**章节划分：**
```markdown
# 主标题

## 1. 概述

## 2. 核心概念

## 3. 使用方法

## 4. 最佳实践

## 5. 常见问题
```

**表格使用：**
```markdown
| 名称 | 类型 | 说明 |
|------|------|------|
| Hook | 事件 | 自动触发的检查 |
| Agent | 智能体 | 专门的 AI 助手 |
```

## 二、JSON - 配置语言 ⭐⭐⭐⭐⭐

### 2.1 为什么重要？

**用途：**
- Hook 配置（hooks/hooks.json）
- 插件元数据（plugin.json）
- MCP 服务器配置（.mcp.json）
- 项目设置文件

**特点：**
- 严格的数据格式
- 机器可读
- 支持嵌套结构

### 2.2 必学知识点

#### 知识点 1：基础语法

**基本数据类型：**

```json
{
  "字符串": "hello world",
  "数字": 42,
  "布尔值": true,
  "null 值": null,
  "数组": [1, 2, 3],
  "对象": {"嵌套": "值"}
}
```

**语法规则：**
- ✅ 键名必须用双引号 `"key"`
- ✅ 值可以是字符串、数字、布尔值、数组、对象
- ✅ 键值对用冒号分隔 `key: value`
- ✅ 多个键值对用逗号分隔
- ❌ 不能有注释
- ❌ 最后不能有逗号

#### 知识点 2：Hook 配置结构

**基本格式：**
```json
{
  "description": "Hook 描述（可选）",
  "hooks": {
    "事件类型": [
      {
        "type": "hook 类型",
        "具体配置": "..."
      }
    ]
  }
}
```

**完整示例：**
```json
{
  "description": "安全检查 Hook",
  "hooks": {
    "PreToolUse": [
      {
        "type": "prompt",
        "prompt": "检查这个操作是否有安全风险",
        "timeout": 30
      },
      {
        "type": "command",
        "command": "bash ./check.sh",
        "timeout": 10
      }
    ],
    "Stop": [
      {
        "type": "prompt",
        "prompt": "最终安全检查",
        "timeout": 30
      }
    ]
  }
}
```

#### 知识点 3：环境变量占位符

**语法：** `${变量名}`

**示例：**
```json
{
  "command": "bash ${CLAUDE_PLUGIN_ROOT}/scripts/check.sh",
  "env": {
    "API_KEY": "${MY_API_KEY}",
    "DATABASE_URL": "${DB_URL}"
  }
}
```

**常用占位符：**
- `${CLAUDE_PLUGIN_ROOT}` - 插件根目录
- `${TOOL_INPUT}` - 工具输入内容
- `${用户自定义}` - 用户的环境变量

#### 知识点 4：MCP 配置

**stdio 类型：**
```json
{
  "filesystem": {
    "command": "npx",
    "args": ["-y", "@modelcontextprotocol/server-filesystem", "/allowed/path"],
    "env": {
      "LOG_LEVEL": "debug"
    }
  }
}
```

**SSE 类型：**
```json
{
  "asana": {
    "type": "sse",
    "url": "https://mcp.asana.com/sse"
  }
}
```

**HTTP 类型：**
```json
{
  "api-service": {
    "type": "http",
    "url": "https://api.example.com/mcp",
    "headers": {
      "Authorization": "Bearer ${API_TOKEN}"
    }
  }
}
```

### 2.3 常见错误

**错误 1：缺少引号**
```json
// ❌ 错误
{
  name: "value"
}

// ✅ 正确
{
  "name": "value"
}
```

**错误 2：多余的逗号**
```json
// ❌ 错误
{
  "key": "value",
}

// ✅ 正确
{
  "key": "value"
}
```

**错误 3：注释**
```json
// ❌ 错误 - JSON 不支持注释
{
  "key": "value" // 这是注释
}

// ✅ 正确做法 - 不要写注释
{
  "key": "value"
}
```

## 三、Bash/Shell - 脚本语言 ⭐⭐⭐⭐

### 3.1 为什么重要？

**用途：**
- Hook 脚本（验证、检查）
- 自动化脚本（安装、部署）
- 工具脚本（验证、测试）

**特点：**
- 直接操作系统
- 快速执行简单任务
- 与其他工具集成方便

### 3.2 必学知识点

#### 知识点 1：基础语法

**Shebang（脚本开头）：**
```bash
#!/bin/bash
```

**变量定义：**
```bash
NAME="John"
AGE=25
echo "Hello $NAME"  # 使用变量
```

**条件判断：**
```bash
if [ "$AGE" -gt 18 ]; then
    echo "成年人"
else
    echo "未成年人"
fi
```

**循环：**
```bash
# for 循环
for i in 1 2 3; do
    echo "数字：$i"
done

# while 循环
count=0
while [ $count -lt 5 ]; do
    echo "计数：$count"
    count=$((count + 1))
done
```

**函数：**
```bash
greet() {
    local name=$1
    echo "Hello, $name!"
}

greet "Alice"
```

#### 知识点 2：文件操作

**读取文件：**
```bash
# 读取整个文件
cat file.txt

# 读取前 10 行
head file.txt

# 读取后 10 行
tail file.txt

# 逐行读取
while IFS= read -r line; do
    echo "$line"
done < file.txt
```

**写入文件：**
```bash
# 覆盖写入
echo "内容" > file.txt

# 追加写入
echo "内容" >> file.txt
```

**文件判断：**
```bash
if [ -f "file.txt" ]; then
    echo "文件存在"
fi

if [ -d "./folder" ]; then
    echo "目录存在"
fi
```

#### 知识点 3：命令执行

**执行命令并获取结果：**
```bash
current_dir=$(pwd)
echo "当前目录：$current_dir"

# 执行 git 命令
git_status=$(git status --porcelain)
```

**条件执行：**
```bash
# 成功才执行下一个
command1 && command2

# 失败才执行下一个
command1 || command2
```

#### 知识点 4：参数处理

**位置参数：**
```bash
#!/bin/bash

echo "第一个参数：$1"
echo "第二个参数：$2"
echo "所有参数：$@"
echo "参数个数：$#"
```

**选项解析：**
```bash
#!/bin/bash

while getopts "a:b:" opt; do
    case $opt in
        a)
            echo "参数 a: $OPTARG"
            ;;
        b)
            echo "参数 b: $OPTARG"
            ;;
    esac
done
```

### 3.3 实战示例

**示例 1：Agent 验证脚本**
```bash
#!/bin/bash
# validate-agent.sh

AGENT_FILE="$1"

echo "验证 Agent: $AGENT_FILE"

# 检查文件是否存在
if [ ! -f "$AGENT_FILE" ]; then
    echo "❌ 文件不存在"
    exit 1
fi

# 提取 frontmatter
FRONTMATTER=$(sed -n '/^---$/,/^---$/p' "$AGENT_FILE" | grep -v '^---$')

# 检查 name 字段
NAME=$(echo "$FRONTMATTER" | grep '^name:' | sed 's/name: *//')
if [ -z "$NAME" ]; then
    echo "❌ 缺少 name 字段"
    exit 1
fi

echo "✅ 验证通过"
```

**示例 2：Hook 检查脚本**
```bash
#!/bin/bash
# safety-check.sh

TOOL_INPUT="$1"

# 检查是否包含危险命令
if echo "$TOOL_INPUT" | grep -q "rm -rf"; then
    echo "⚠️  警告：检测到危险操作 rm -rf"
    exit 1
fi

if echo "$TOOL_INPUT" | grep -q "sudo"; then
    echo "⚠️  警告：检测到 sudo 提权操作"
    exit 1

echo "✅ 安全检查通过"

```

#### 知识点 4：Hook 处理示例

```python
#!/usr/bin/env python3
"""
Hook 处理示例：验证工具调用
"""

import json
import sys

def validate_tool_use(tool_input):
    """验证工具输入是否安全"""
    
    dangerous_patterns = [
        "rm -rf",
        "sudo",
        "DROP TABLE",
        "<script>"
    ]
    
    for pattern in dangerous_patterns:
        if pattern.lower() in tool_input.lower():
            return False, f"检测到危险模式：{pattern}"
    
    return True, "安全检查通过"

def main():
    # 从命令行参数或标准输入获取数据
    if len(sys.argv) > 1:
        tool_input = sys.argv[1]
    else:
        tool_input = input()
    
    # 验证
    is_safe, message = validate_tool_use(tool_input)
    
    # 输出结果
    result = {
        "safe": is_safe,
        "message": message
    }
    
    print(json.dumps(result))
    
    # 返回状态码
    sys.exit(0 if is_safe else 1)

if __name__ == "__main__":
    main()
```
