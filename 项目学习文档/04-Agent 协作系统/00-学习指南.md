### 04-Agent vs Skill 机制对比.md ⭐⭐⭐⭐⭐

**内容概要：** 深入解析 Agent 和 Skill 两种扩展机制的区别

**核心对比：**

| 维度 | Agent | Skill |
|------|-------|-------|
| **本质** | 执行专家 | 知识顾问 |
| **触发** | 显式/隐式调用 | 自动检测触发 |
| **存在感** | 强烈（独立输出） | 透明（融入回答） |
| **交付物** | 独立报告/方案 | 无（知识注入） |
| **工作模式** | 主动执行 | 被动支持 |

**经典比喻：**
```
Agent = 外部咨询公司
    - 有专门问题时聘请
    - 独立完成项目
    - 提交正式报告
    
Skill = 内部资深顾问
    - 一直在你身边
    - 随时提供建议
    - 不独立执行任务
```

**关键收获：**
- ✅ 清晰理解两者区别
- ✅ 知道何时使用 Agent
- ✅ 知道何时使用 Skill
- ✅ 避免常见误区

**建议学习时长：** 1 天

### 06-Agent-Hook 配合实战.md ⭐⭐⭐⭐⭐

**内容概要：** Agent 与 Hook 如何协同工作，确保任务质量和安全性

**核心内容：**

#### 1. 三层防护架构
```
PreToolUse Hook → 事前预防型检查（安全检查）
    ↓
PostToolUse Hook → 事中监控型验证（操作验证）
    ↓
Stop Hook → 事后审计型审查（完整性检查）
```

#### 2. security-guidance 的 PreToolUse Hook
- **安全模式**：GitHub Actions 注入、命令注入、XSS 攻击等
- **检测方式**：路径检测 + 内容检测
- **会话级去重**：同一问题只警告一次

#### 3. feature-dev 的七阶段检查
- **Phase 1-7 完整性验证**
- **问题修复追踪**
- **人性化裁决机制**

#### 4. 完整实战案例
开发积分系统的全流程演示：
- code-explorer 分析现有代码
- code-architect 设计架构
- PreToolUse Hook 拦截 exec 调用
- code-reviewer 审查质量
- Stop Hook 验证完整性

**关键收获：**
- ✅ 理解 Agent-Hook 协作原理
- ✅ 掌握三层防护架构
- ✅ 学会配置安全检查
- ✅ 可以设计自己的 Hook

**建议学习时长：** 2-3 天
