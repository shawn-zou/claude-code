# 📎 插件开发速查卡片

## 一、Hookify 规则模板

### 简单规则（单条件）

```markdown
---
name: rule-name
enabled: true
event: bash
pattern: your-regex
action: warn
---

## ⚠️ 警告标题

**检测到：** 问题描述

**风险：**
- 风险 1
- 风险 2

**解决方案：**
1. 步骤 1
2. 步骤 2
```

---

### 复杂规则（多条件）

```markdown
---
name: advanced-rule
enabled: true
event: file
action: block
conditions:
  - field: file_path
    operator: regex_match
    pattern: \.(ts|tsx)$
  - field: new_text
    operator: contains
    pattern: API_KEY
---

## 🔐 高级规则

详细内容...
```

## 二、Event 类型速查

| Event | 触发时机 | 常用字段 | 示例场景 |
|-------|---------|---------|---------|
| **bash** | Bash 命令 | `command` | 拦截危险命令 |
| **file** | 文件编辑 | `file_path`, `new_text` | 代码规范检查 |
| **stop** | 想要停止 | `transcript` | 完成度检查 |
| **prompt** | 用户提问 | `user_prompt` | 敏感问题检测 |
| **all** | 所有事件 | `content` | 全局规则 |

---

## 三、正则表达式速查

| 模式 | 含义 | 示例 |
|------|------|------|
| `\s+` | 1 个或多个空白 | `rm\s+-rf` |
| `\.` | 字面意义的点 | `console\.log` |
| `$` | 行尾 | `\.env$` |
| `^` | 行首 | `^import` |
| `|` | 或 | `eval\|exec` |
| `()` | 分组 | `(foo\|bar)` |
| `.*` | 任意字符任意次 | `TODO.*FIXME` |

---

## 四、Operator 速查

| Operator | 含义 | 示例 |
|----------|------|------|
| `regex_match` | 正则匹配 | `pattern: \.env$` |
| `contains` | 包含 | `pattern: KEY` |
| `equals` | 等于 | `pattern: production` |
| `not_contains` | 不包含 | `pattern: TODO` |
| `starts_with` | 开头是 | `pattern: /src/` |
| `ends_with` | 结尾是 | `pattern: .test.ts` |

    "command": "node",
    "args": ["${CLAUDE_PLUGIN_ROOT}/server.js"],

## 七、标准目录结构

```
plugin-name/
├── .claude-plugin/
│   └── plugin.json          # 必需：manifest
├── commands/                 # 可选：自定义命令
│   └── my-command.md
├── agents/                   # 可选：专门助手
│   └── my-agent.md
├── skills/                   # 可选：技能文档
│   └── my-skill/
│       ├── SKILL.md
│       └── references/
├── hooks/                    # 可选：自动化钩子
│   ├── hooks.json
│   └── scripts/
├── .mcp.json                 # 可选：MCP 服务器
├── README.md                 # 必需：使用说明

```

## 十、常见问题快速诊断

### Hook 不生效

1. 检查文件位置：`.claude/hookify.*.local.md`
2. 检查 YAML 格式是否正确
3. 检查 enabled 是否为 true
4. 检查 pattern/conditions 是否合理

### MCP 无法连接

1. 检查 .mcp.json 格式
2. 检查环境变量是否设置
3. 检查网络连接
4. 查看 debug 日志

### Agent 无响应

1. 检查 frontmatter 完整性
2. 检查 description 是否包含示例
3. 检查 model 值是否合法
4. 检查 tools 数组是否正确
