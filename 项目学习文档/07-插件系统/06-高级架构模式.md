## 架构模式预览

### 模式 1：分层架构

```
my-plugin/
├── commands/              # 表现层 - 用户接口
│   ├── user-facing.md
│   └── admin.md
├── agents/                # 编排层 - 任务协调
│   ├── orchestrator.md
│   └── specialist.md
├── skills/                # 知识层 - 领域知识
│   ├── domain-expert/
│   │   ├── SKILL.md
│   │   └── references/
│   └── utils/
│       └── SKILL.md
├── lib/                   # 核心层 - 业务逻辑
│   ├── core/
│   │   ├── validator.js
│   │   └── processor.py
│   ├── integrations/
│   │   ├── github.js
│   │   └── database.py
│   └── utils/
│       └── helpers.js
└── hooks/                 # 自动化层
    ├── hooks.json
    └── scripts/
```

---

### 模式 2：模块化扩展

```
enterprise-plugin/
├── core/                  # 核心功能（必需）
│   ├── commands/
│   ├── agents/
│   └── skills/
├── extensions/            # 可选扩展
│   ├── github-integration/
│   │   ├── commands/
│   │   ├── agents/
│   │   └── .mcp.json
│   ├── jira-integration/
│   │   └── ...
│   └── slack-integration/
│       └── ...
└── plugin.json

# plugin.json 配置
{
  "commands": [
    "./core/commands",
    "./extensions/github-integration/commands",
    "./extensions/jira-integration/commands"
  ]
}
```
