## 核心工具

### 1. Hook Schema 验证器

**位置**：`plugins/plugin-dev/scripts/validate-hook-schema.sh`

**用途**：验证 hooks.json 文件格式是否正确

**使用方法**：
```bash
cd plugins/my-plugin
./scripts/validate-hook-schema.sh hooks/hooks.json
```

**验证内容**：
- ✅ JSON 语法正确性
- ✅ 必需字段存在性
- ✅ event 名称合法性
- ✅ hook 类型正确性
- ✅ command 引用有效性

---

### 2. Agent 格式验证器

**位置**：`plugins/plugin-dev/scripts/validate-agent.sh`

**用途**：验证 agents/*.md 文件格式

**验证内容**：
- ✅ YAML frontmatter 完整性
- ✅ name 字段格式（kebab-case）
- ✅ description 包含示例
- ✅ model 值合法性
- ✅ color 值合法性
- ✅ tools 数组正确性
- ✅ system prompt 充分性

---

### 3. Plugin Validator Agent

**位置**：`plugins/plugin-dev/agents/plugin-validator.md`

**用途**：完整的插件验证（所有组件）

**验证范围**：
- plugin.json manifest
- commands/*.md
- agents/*.md
- skills/*/SKILL.md
- hooks/hooks.json
- .mcp.json
- README.md
- 文件组织
- 安全检查
