# Claude Code 项目概述

## 一、项目简介

### 1.1 什么是 Claude Code？

**Claude Code** 是 Anthropic 公司开发的一款**智能编程助手**，它生活在你的终端中，能够理解你的代码库，并通过自然语言命令帮助你更高效地编写代码。

**简单来说：** Claude Code = AI + 终端 + 代码理解

### 1.2 核心功能

#### 🤖 智能对话
- 用自然语言与 AI 交流
- 询问代码相关问题
- 请求实现特定功能
- 调试和修复错误

#### 📚 代码理解
- 理解整个代码库的结构
- 追踪函数调用关系
- 分析架构模式
- 识别最佳实践

#### 🔧 自动化任务
- 执行 routine 任务（如重构、格式化）
- Git 工作流自动化
- 代码审查
- 测试生成

#### 🛡️ 安全保障
- Hook 系统拦截危险操作
- 安全门机制检查代码质量
- 预防常见错误
- 强制执行规范

## 四、核心特色功能

### 4.1 Hook 系统（事件驱动）

**什么是 Hook？**
Hook 是在特定事件发生时自动触发的检查或操作。

**核心事件类型：**
- **PreToolUse**：工具使用前检查
- **PostToolUse**：工具使用后处理
- **SessionStart**：会话开始初始化
- **Stop**：任务完成前审核

**实际例子：**
```
场景：删除文件

1. 用户让 Claude 删除一个文件
   ↓
2. PreToolUse Hook 触发
   ↓
3. AI 分析："这个文件很重要，确定要删除吗？"
   ↓
4. 用户确认后才删除
```

### 4.2 安全门机制（四层防护）

**第一层：会话提醒**
- 每次开始时提醒注意安全

**第二层：操作前检查**
- 危险操作前进行 AI 评估

**第三层：操作后验证**
- 写完代码后检查安全问题

**第四层：最终审核**
- 任务完成前全面审查

### 4.3 Agent 协作系统

**什么是 Agent？**
Agent 是具有特定专长的 AI 助手。

**典型 Agent：**
- **code-explorer**：探索代码库
- **code-architect**：设计架构方案
- **code-reviewer**：审查代码质量
- **security-agent**：检查安全性

**协作方式：**
```
复杂任务 → 分解为子任务 → 分配给不同 Agent → 整合结果
```

### 4.4 七阶段流程（feature-dev）

完整的feature开发流程：

1. **Discovery**：理解需求
2. **Codebase Exploration**：探索代码库
3. **Clarifying Questions**：澄清问题
4. **Architecture Design**：设计架构
5. **Implementation**：实现功能
6. **Quality Review**：质量审查
7. **Summary**：总结文档

### 4.5 插件系统

**插件是什么？**
插件是可扩展的功能包，包含：
- Commands（命令）
- Agents（智能体）
- Skills（技能）
- Hooks（钩子）

**官方插件示例：**
| 插件名 | 功能 | 核心内容 |
|--------|------|----------|
| feature-dev | 功能开发 | 七阶段流程、3 个 Agent |
| security-guidance | 安全检查 | PreToolUse Hook |
| code-review | 代码审查 | 多 Agent 并行审查 |
| hookify | Hook 开发 | 对话分析、规则创建 |
